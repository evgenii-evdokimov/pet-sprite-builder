# Pet Sprite Builder

Десктопное приложение для сборки спрайт-листов питомцев для Orca из фото и GIF.

## Возможности
- 9 состояний питомца (idle, running, waving, …), фото или GIF на состояние.
- Вырезание фона (rembg), хромакей для GIF, обрезка, привязка, покачивание.
- Видео (MP4/MOV/WebM/MKV/AVI) автоматически конвертируется в GIF через ffmpeg.
- Ручной выбор/порядок/длительность кадров GIF, единый масштаб, безопасная зона.
- Предпросмотр с фоном и petSize, экспорт GIF/APNG, ZIP, импорт bundle.
- Экспорт bundle для импорта в Orca (без изменения её БД).

## Обновления
Приложение проверяет манифест [latest.json](latest.json). Установщики — в разделе **Releases**.

Схема версий: `1.1.9 → 1.2.0` (патч не больше 9).
